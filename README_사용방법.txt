JOB ZIP v10 — 링크 자동 분석 (Vercel 배포용)

이 버전은 API 신청이나 Python 설치가 필요 없습니다.
대신 링크 자동 분석에는 Vercel의 서버 기능이 필요합니다. HTML 파일을 더블클릭한 경우에는 링크만 저장하거나 원문 붙여넣기만 사용할 수 있습니다.

기존 Vercel 사이트에 업데이트:
1. ZIP을 내려받고 압축을 풉니다.
2. 기존 JOB ZIP GitHub 저장소로 이동하여 index.html, package.json, vercel.json 및 api/, lib/ 폴더를 저장소 최상위에 업로드합니다. ZIP 파일 자체를 업로드하지 마세요.
3. 기존 파일은 덮어쓰고, 변경사항을 Commit합니다.
4. Vercel에서 자동 배포가 끝나면 Deployments > Ready 확인 후 기존 웹주소를 열어봅니다.
5. 사이트에서 ‘링크로 가져오기’ → 공고 URL만 입력 → ‘자동 정리하기’를 누릅니다.
6. 제목, 기업명, 담당 업무, 자격 요건, 마감일이 채워진 결과를 확인하고 직접 수정 후 저장합니다.

중요:
- 접근 가능한 공개 HTML / 구조화된 채용공고 데이터만 추출됩니다.
- 사람인, 잡코리아, 네이버 카페에서 서버 접근을 차단하거나 글 내용이 이미지·로그인 영역에 있으면 자동 추출이 실패하거나 일부 정보만 확인될 수 있습니다. 이를 우회하지 않습니다.
- 제목만 읽혔다면 업무·요건 등은 빈칸으로 남기며, 원문에서 확인해 수정해야 합니다.
- 원본 URL을 ‘링크만 저장’하거나, 공고 텍스트를 붙여넣어 자동 분류하는 기능은 계속 사용할 수 있습니다.
- 현재 저장된 목록은 브라우저 localStorage에 있습니다. 도메인을 옮기거나 새 기기를 쓰기 전에는 ‘설정 → JSON 백업’을 해주세요.
- 신규 채용공고를 매일 자동으로 수집하는 프로그램은 아닙니다.
- 실제 사람인·잡코리아 사이트의 실시간 응답은 이 제작 환경에서 확인하지 못했습니다. 공개 HTML 모의 응답으로 서버 파싱과 UI 연결을 테스트했습니다.

파일 목록:
index.html: 전체 사이트 화면, 브라우저 저장 및 공고 관리
api/extract.js: Vercel 서버 함수 /api/extract
lib/extract.cjs: 공개 HTML 분석 및 구조화된 JobPosting 데이터 추출
vercel.json, package.json: 배포 설정
